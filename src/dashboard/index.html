System Design
3-Layer Architecture
Every patient interaction flows through three layers ��� from raw hospital data to actionable clinical treatment plan.
Layer 1

Data Ingestion

  • FHIR R4 patient bundlesFHIR (Fast Healthcare Interoperability Resources) is the global standard for exchanging patient data between hospital systems.
  • LOINC-coded vitals and labs
  • Clinical notes (free text)
  • Completeness validation
Layer 2

AI Core

  • XGBoost sepsis model + SHAPXGBoost: a fast gradient-boosting ML model trained on patient vitals. SHAP explains which features drove each prediction.
  • scispaCy NLP (NER + negation)NLP pipeline that reads clinical notes, extracts medical entities (symptoms, diagnoses, drugs) and detects negations like "no fever".
  • Multimodal fusion engine
  • LangGraph agent orchestrationLangGraph chains AI steps (triage ��� model ��� NLP ��� fusion ��� treatment) into a traceable, auditable pipeline.
Layer 3

Clinical Output

  • Risk level + score + driversRisk score (0-100%) from XGBoost. Drivers are the top SHAP features that pushed the score up or down.
  • Treatment plan (immediate/urgent/routine)
  • Escalation triggers
  • HITL mandatory review flagHuman-In-The-Loop: for HIGH/CRITICAL patients, the system flags that a doctor must review before acting on AI output.
